# Shadow Cipher

Aplicação estática para cifrar e decifrar mensagens com as tabelas Shadow Cipher.

Os algarismos usam deslocamento circular de +7 (por exemplo, `0→7`, `1→8`, `9→6`).

## Executar

Abre `index.html` num navegador moderno. Não precisa de servidor, instalação ou conta.

## Usar

Escolhe **Decifrar** ou **Cifrar**, escreve ou cola o texto e executa a operação. O exemplo carrega `Rpr?]` no modo de decifração ou `Olá!` no modo de cifra.
